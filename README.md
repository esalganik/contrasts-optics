# Orthomosaic plotting script

This repository contains:

- plot_orthomosaic.m

The script extracts a user-defined subset of a georeferenced orthomosaic
(GeoTIFF), computes a simple brightness-derived albedo transect, and
overlays the albedo values on the image.

Output:
- Orthomosaic_1B.tif

Requirements:
- MATLAB
- Mapping Toolbox
- Optional: Crameri colormaps (e.g., buda.mat)

Developed for:
"Contrasting Optical Properties of Different Arctic Sea Ice Regimes"

F. Zimmer, R. Tao, T. Blei, E. Salganik, M. Nicolaus
